# Algoritmos de Ciência da Computação

Implementações didáticas de algoritmos e estruturas de dados clássicos em Python, cada uma com testes (`unittest`, sem dependências externas).

## Rodando os testes

```bash
python3 -m unittest discover -s tests -v
```
