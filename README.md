# Algoritmos de Ciência da Computação

Implementações didáticas de algoritmos e estruturas de dados clássicos em Python, cada uma com testes (`unittest`, sem dependências externas).

## Rodando os testes

```bash
python3 -m unittest discover -s tests -v
```

## Conteúdo

Cada módulo fica em `algoritmos/` e tem o teste correspondente em `tests/`.
- **Busca binária** — [`algoritmos/busca_binaria.py`](algoritmos/busca_binaria.py)
